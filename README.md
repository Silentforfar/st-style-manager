# 文风管理器（st-style-manager）

把喜欢的文风存成一个个**标签**，点一下点亮、可以同时点亮多个；预设里只写一个 `{{style}}`，切换风格时点几下标签就生效，不用再改预设。

适用于 [SillyTavern](https://github.com/SillyTavern/SillyTavern)（酒馆）。

---

## 功能

- **标签式收集**：每种文风是一个标签，点击点亮 / 再点取消，支持多选
- **实时切换**：`{{style}}` 在每次构建提示词时求值，切换即刻生效
- **多选组合**：点亮多个文风时，按**点亮顺序**拼接成一段正文插入
- **内置 5 种示例文风**：冷峻克制 / 细腻感官 / 古典雅正 / 轻快幽默 / 悬疑压迫，既是示例也是模板
- **悬浮窗**：从聊天框左下角**魔棒菜单**打开，随时切换，与设置页实时同步，位置可拖动并记住
- **高度限界**：标签区和列表都有高度上限，文风再多也不会把设置页撑爆
- **搜索**：按名称、标签、正文内容搜索
- **导入 / 导出**：导出为 JSON 备份，或分享给别人；导入自动去重、不覆盖已有内容
- **数据跟随账号**：存在酒馆的 `settings.json` 里，换设备访问同一个酒馆时保持一致

## 安装

### 方式一：酒馆内安装（推荐）

1. 打开酒馆 → 顶部**扩展**图标（拼图块）
2. 点 **Install extension**（安装扩展）
3. 粘贴本仓库地址：

```
https://github.com/ZHD/st-style-manager
```

4. 确认后刷新页面

> 注：仓库地址以实际发布地址为准。

### 方式二：手动安装

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/ZHD/st-style-manager
```

然后刷新酒馆页面。

## 使用

1. 打开酒馆右侧 **扩展设置** 抽屉，找到「**文风管理器**」，点标题展开
2. 点「新建文风」，粘贴一段你喜欢的文风描述（语气、句式、用词、节奏、禁忌），保存
3. 在想用的文风标签上**点一下**（亮起即为选中，可多选）
4. 打开**预设**或系统提示，在合适位置写：

```
{{style}}
```

之后想换风格，只要在面板或悬浮窗上点标签即可，预设不用再动。

### 悬浮窗

聊天框左下角**魔棒菜单**（🪄）→「文风管理器」→ 弹出悬浮窗；再点一次收起。

- 可拖动，位置会记住
- 里面的标签与设置页**完全同步**
- 底部「复制 `{{style}}`」方便贴进预设

## 宏说明

| 写法 | 说明 |
|---|---|
| `{{style}}` | 所有点亮文风的组合正文（未点亮时为空） |

组合规则：按**点亮顺序**用空行连接。例如先点「冷峻克制」再点「悬疑压迫」，得到的顺序就是这两个顺序。

建议放在系统提示或预设的开头段，例如：

```
写作要求：以下文风必须严格遵守。
{{style}}
```

## 数据与备份

- 数据存在酒馆的 `data/default-user/settings.json` 的 `extension_settings.styleManager`
- 换电脑 / 重装前，用面板上的「**导出**」存一份 JSON；回来点「**导入**」即可恢复

## 常见问题

**Q：写了 `{{style}}` 但没效果？**
- 确认至少点亮了一个标签（头部会显示「已点亮 N」）
- 确认宏写在**预设 / 系统提示**这类会走宏替换的字段里
- 刷新一次页面

**Q：更新插件后没变化？**
在扩展面板点「更新」，然后**强制刷新**页面（⌘⇧R / Ctrl+Shift+R）。

**Q：会和我现有的预设冲突吗？**
不会。它只提供一个宏，不修改任何预设或聊天数据；不写 `{{style}}` 时它完全不参与。
